# Claymorph documentation

Claymorph is a React + TypeScript UI package for soft, accessible Claymorphism. It provides native components, named color palettes, light/dark themes, and reusable CSS without runtime styling dependencies.

> Version 0.1.0 is implemented locally but remains private and unpublished. See [Releasing](releasing.md) before attempting a release.
